# Cordespace

Code WordPress de Cordespace (studio shibari à Montréal). Ce repo public
contient le plugin **`cordespace-snippets`** — voir
[`plugins/cordespace-snippets/`](plugins/cordespace-snippets/).

## Installation rapide via WP Pusher

1. wp-admin → **WP Pusher** → **Install Plugin**
2. Coller l'URL de ce repo
3. Sous-dossier : `plugins/cordespace-snippets`
4. **Install**

Une fois installé, voir
[`plugins/cordespace-snippets/DEPLOIEMENT.md`](plugins/cordespace-snippets/DEPLOIEMENT.md)
pour la procédure d'activation.

## Contenu

- `plugins/cordespace-snippets/` — glue entre Amelia, MyCred, User Switching,
  WooCommerce (shortcode `[cordespace_mon_espace]`, toggle de présence prof,
  bascule entre comptes liés, callouts éditoriaux)
